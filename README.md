2. Download it from the official project website and follow its Windows, Docker, or server installation instructions.
3. Configure storage, network access, and administrator settings before adding your personal data.

## 🔥 Key Features

### ☁️ Personal Cloud and Storage
- 📁 **Nextcloud** — Host personal files, calendars, contacts, and collaboration services.

- 🖼️ **Immich** — Manage and back up personal photo and video libraries.

- 🎧 **Audiobookshelf** — Organize audiobooks, podcasts, and listening progress.

### 🏠 Home Lab and Smart Home
- 🏡 **Home Assistant** — Manage smart home devices and automations.
- 📦 **Docker** — Run applications in isolated containers.
- 🖥️ **Proxmox VE** — Manage virtual machines and containers on supported server hardware.

- 📊 **Uptime Kuma** — Monitor services and receive availability notifications.
- 🐳 **Portainer** — Manage Docker environments through a web interface.
- 🌐 **AdGuard Home** — Manage network-wide DNS filtering.
- 💾 **Restic** — Create encrypted backups of important data.

## ❓ FAQ

**Do I need to run it as Administrator?**

Yes — admin rights are required for the overlay to attach.

**Is personal server software free?**

Many popular self-hosted projects are free and open source. Some offer paid editions, optional hosted services, or commercial support.

**Can I run a personal server on Windows 11?**

Yes. Some applications support Windows directly, while others are commonly deployed through Docker or a Linux virtual machine. Check each project's installation requirements.

**Which personal server software is best for beginners?**

CasaOS provides a graphical approach to managing self-hosted applications. Jellyfin is a practical starting point for building a personal media server.

**Can I access my personal server remotely?**

Yes. Remote access can be configured using a VPN or supported secure access method. Configure authentication, updates, and backups before exposing any service outside your local network.
